# LiHub

Plataforma web em desenvolvimento voltada à gestão comercial de pequenos negócios.

O LiHub está sendo desenvolvido com foco em organização de produtos, estoque e vendas, buscando oferecer uma experiência simples e prática para micro e pequenos empreendedores.

## Sobre o projeto

O projeto surgiu como uma solução própria para centralizar funcionalidades importantes de uma operação comercial em uma única plataforma.

Atualmente, o LiHub possui funcionalidades de frontend já desenvolvidas e está evoluindo para backend, autenticação e persistência de dados.

## Funcionalidades em desenvolvimento

- Gestão de produtos
- Controle de estoque
- Vitrine de produtos
- Fluxo de vendas
- Organização de variações e disponibilidade
- Autenticação de usuários
- Persistência de dados
- Integração entre frontend e backend

## Tecnologias e ferramentas

- React
- JavaScript
- Git e GitHub
- VS Code
- PowerShell
- Supabase
- PostgreSQL
- Docker em aprendizado

## Arquitetura e evolução

O projeto está evoluindo de uma aplicação inicialmente local para uma arquitetura com backend e banco de dados.

Atualmente, estou trabalhando na integração com Supabase e PostgreSQL, além de autenticação e estruturação das regras de acesso.

## Aprendizados

Durante o desenvolvimento do LiHub, venho praticando:

- Desenvolvimento de interfaces
- Organização de componentes
- Versionamento com Git e GitHub
- Uso de branches, commits e merge
- Fundamentos de backend
- Banco de dados
- Autenticação
- Uso de terminal
- Docker em ambiente local
- Uso de IA como apoio a pesquisa, debugging e revisão de código

## Status

🚧 Projeto em desenvolvimento.

O código-fonte principal permanece privado, pois o LiHub é um projeto próprio com intenção comercial.
